# Калибровка осей

## Где хранятся данные

Файл `config/calibration.json` — проектный журнал калибровки. Он хранит:

- `steps_per_unit` для каждой оси;
- единицы измерения;
- фактические пределы хода после настройки концевиков.

Рабочее значение в контроллере хранится в EEPROM Marlin. После подтверждённой калибровки его записываем командами:

```gcode
M92 X<значение>
M500
```

JSON сохраняем одновременно как резервную копию и историю проекта.

## Формула

1. Установить текущую координату в ноль кнопкой **Ноль** или командой `G92 X0`.
2. Выполнить тестовый ход, например 10 мм.
3. Измерить фактический ход.
4. Рассчитать:

```text
new_steps = old_steps * commanded_distance / measured_distance
```

Пример: задано 10 мм, фактически 8 мм, старое значение 80:

```text
80 * 10 / 8 = 100 steps/mm
```

Для A/B вместо мм используем градусы и получаем `steps/degree`.

## Безопасный порядок

- Калибровать одну ось за раз.
- Сначала использовать 5–10 единиц и низкую подачу.
- Перед тестом проверить оба концевика этой оси.
- Не запускать `G28`, пока логика и положение концевиков не проверены.
- После изменения `M92` выполнить `M500` только после проверки результата.

## Обнуление

Кнопка **Ноль** отправляет `G92 <ось>0`. Это меняет текущую систему координат, но не калибрует механику и не заменяет `G28`.
