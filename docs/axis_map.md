# Раскладка осей и концевиков TomoRamps

## 1. Шаговые двигатели

| Слот RAMPS | Пины STEP/DIR/ENABLE Mega | Ось G-code | Назначение |
|---|---|---|---|
| X | D54 / D55 / D38 | X | Точная ось X, микровинт |
| Y | D60 / D61 / D56 | Y | Точная ось Y, микровинт |
| Z | D46 / D48 / D62 | Z | Грубая ось, направляющая 1 м |
| E0 | D26 / D28 / D24 | B | Наклон |
| E1 | D36 / D34 / D30 | A | Вращение |
| Внешний TB6600 | D40 / D42 / D44 | C | Точная ось Z |

В G-code дополнительные моторы используются как `A`, `B` и `C`: `A` = вращение (слот E1), `B` = наклон (слот E0), `C` = точная ось Z через TB6600.

## Внешний TB6600 для оси C

| TB6600 | Arduino Mega / RAMPS | Назначение |
|---|---:|---|
| PUL+ | D40 | STEP |
| DIR+ | D42 | DIR |
| ENA+ | D44 | ENABLE |
| PUL-, DIR-, ENA- | GND Mega/RAMPS | общий сигналовый GND |
| A+, A-, B+, B- | 4 провода шагового мотора | две обмотки |
| VCC/+ | +12..36 V отдельного питания TB6600 | силовое питание |
| GND/- | минус того же блока питания | силовой GND |

Для первого теста можно оставить ENA неподключённым только если это разрешено инструкцией конкретного TB6600; безопаснее подключить его по схеме входов вашего модуля. Не соединяйте выходы RAMPS с выходами A+/A-/B+. D40/D42/D44 — это логические 5-вольтовые сигналы, а мотор питается только от TB6600.

⚠️ Эти три пина ранее использовались как резервные CS/концевики. После включения C нельзя использовать D40/D42/D44 для других функций; концевики A/B через D42/D44 пока считаются неподключёнными.
Для первого испытания используется только слот X.

## 2. Концевики RAMPS 1.6

На каждом трёхконтактном разъёме RAMPS есть контакты `S`, `-`, `+`.
Для обычного механического концевика на первом этапе подключайте **COM к `-` (GND), NO к `S`**. Контакт `+` не подключайте.

| Разъём | Пин Arduino Mega | Статус сейчас |
|---|---:|---|
| **X_MIN (X−)** | **D3** | **подключить первым** |
| X_MAX (X+) | D2 | не подключен |
| Y_MIN (Y−) | D14 | не подключен |
| Y_MAX (Y+) | D15 | не подключен |
| Z_MIN (Z−) | D18 | не подключен |
| Z_MAX (Z+) | D19 | не подключен |
| E-STOP, 2-pin | D4 | не подключен; оставить резервом |
| A_MIN, дополнительный | D42 | не подключен |
| B_MIN, дополнительный | D44 | не подключен |

### Что подключить сейчас

Подключите **один** концевик точной оси X к разъёму **X_MIN** RAMPS:

```text
концевик COM -> RAMPS X_MIN: - (GND)
концевик NO  -> RAMPS X_MIN: S (сигнал)
RAMPS X_MIN: + -> не подключать
```

Если на вашем концевике нет маркировки COM/NO/NC, пришлите фотографию или прозвоните контакты мультиметром. Не подключайте питание `+` наугад.

Пока остальные концевики не подключены, **не запускайте G28**. Неподключённые входы могут показываться как `TRIGGERED` или `open` — это не является проверкой их исправности.

Проверка X-концевика выполняется только командой `M119`: нажали/отпустили рукой и сравнили состояние `x_min`.

## 3. DC-мотор и L298N — пока не подключать

Это отдельный будущий этап. Для него потребуются 12 В, общий GND, L298N и отдельная проверка направления. До завершения теста оси X DC-мотор оставляем отключённым.
