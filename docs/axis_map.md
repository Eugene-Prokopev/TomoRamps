# Фактическая распиновка TomoRamps

## Оси

| Ось в приложении | Физическое назначение | Драйвер |
|---|---|---|
| X | точная X, микровинт | RAMPS X / A4988 |
| Y | точная Y, микровинт | RAMPS Y / A4988 |
| Z | грубая X, направляющая 1 м | RAMPS Z / A4988 |
| A | вращение образца | RAMPS E1 / A4988 |
| B | наклон | RAMPS E0 / A4988 |
| C | точная Z | внешний TB6600 |

## Шаговые выходы

| Ось/слот | STEP | DIR | ENABLE |
|---|---:|---:|---:|
| X | D54 | D55 | D38 |
| Y | D60 | D61 | D56 |
| Z | D46 | D48 | D62 |
| B / E0 | D26 | D28 | D24 |
| A / E1 | D36 | D34 | D30 |
| C / TB6600 | D40 | D42 | D44 |

Для оси C D40/D42/D44 — это логические сигналы Mega: STEP/DIR/ENABLE.
Мотор C подключается к выходам A+/A-/B+/B- TB6600, а не к RAMPS.

## Концевики: окончательная схема

Все установленные концевики — механические `NO`.
Для каждого используется:

```text
COM концевика → контакт `-` разъёма RAMPS (GND)
NO концевика  → контакт `S` разъёма RAMPS (SIGNAL)
контакт `+`   → не подключать
```

| Физическая ось | Ось Marlin | MIN-разъём | Пин Mega | MAX-разъём | Пин Mega | Статус |
|---|---|---|---:|---|---:|---|
| Точная X | X | X_MIN | D3 | X_MAX | D2 | установлены |
| Точная Y | Y | Y_MIN | D14 | Y_MAX | D15 | установлены |
| Грубая X | Z | Z_MIN | D18 | Z_MAX | D19 | установлены |
| Точная Z | C | AUX signal | D11 | AUX signal | D6 | установлены |
| Вращение | A | — | — | — | — | концевиков нет |
| Наклон | B | — | — | — | — | концевиков нет |

### Концевики C через AUX

Для внешней оси C используются два свободных логических входа Mega:

```text
C_MIN → D11
C_MAX → D6
```

Уточните маркировку контактов на вашем AUX-разъёме по шелкографии RAMPS перед подключением. Не подавайте 12 В на D32/D39.

Пины D42 и D44 не использовать для концевиков A/B: они заняты DIR/ENABLE внешнего TB6600. D11 и D6 теперь заняты C_MIN/C_MAX.

## Логика концевиков

Для схемы `NO: COM→GND, NO→S` в Marlin используется:

```cpp
*_MIN_ENDSTOP_INVERTING true
*_MAX_ENDSTOP_INVERTING true
```

Ожидаемая проверка `M119`:

```text
отпущен → open
нажат   → TRIGGERED
```

Для A/B концевиков нет, поэтому автоматический `G28 A`/`G28 B` не использовать.
До подключения C-концевиков не запускать `G28 C`.

## Команды безопасной проверки

```gcode
M17              ; включить драйверы
M119             ; состояние концевиков
M114             ; позиции X/Y/Z/A/B/C
M18              ; отключить драйверы
```

Первый тест каждой оси выполнять jog на 0.1–1 единицу при малой подаче.
