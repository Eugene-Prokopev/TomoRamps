# Распиновка RAMPS 1.6 (BIGTREETECH) ↔ Arduino Mega 2560

RAMPS 1.6 электрически идентична RAMPS 1.4/1.5 (отличия: MOSFET и клеммы питания).
Источник: `pins_RAMPS.h` (Marlin 2.1.x), репозиторий bigtreetech/ramps-1.6, RepRap Wiki.

## Шаговые двигатели (слоты драйверов A4988)

| Ось | STEP | DIR | ENABLE | Назначение в проекте |
|-----|------|-----|--------|----------------------|
| X   | D54  | D55 | D38    | TBD |
| Y   | D60  | D61 | D56    | TBD |
| Z   | D46  | D48 | D62    | TBD |
| E0  | D26  | D28 | D24    | TBD (поворот θ?) |
| E1  | D36  | D34 | D30    | TBD |

- Микрошаг: джамперы MS1+MS2+MS3 = 1/16.
- Разъём Z двойной (Z + Z2) — один драйвер, два параллельных мотора.
- Ток A4988: `I ≈ Vref / 1.25`, ставить ~60–70% номинала мотора.

## Концевики (гребёнка: S, −, +; срабатывание = замыкание S↔GND)

| Разъём | Пин |
|--------|-----|
| X− (X_MIN) | D3  |
| X+ (X_MAX) | D2  |
| Y− | D14 |
| Y+ | D15 |
| Z− | D18 |
| Z+ | D19 |
| Доп. 2-pin «E-STOP» | D4 |

## Силовые и служебные выходы

| Разъём | Пин | Использование |
|--------|-----|---------------|
| D8 | D8  | свободен (MOSFET) |
| **D9** | D9 (ШИМ) | **DC-мотор 12 В** — `M106 S0–255` / `M107`, диод катодом к «+» |
| D10 | D10 | свободен (MOSFET) |
| SERVO0–3 | D11, D6, D5, D4 | сервоприводы / BLTouch |
| T0/T1/T2 | A13, A14, A15 | термисторы = свободные аналоговые входы |

## Свободные GPIO

D40, D42, D44 (AUX2), A3–A5, A9–A12 (EXP1/EXP2 задействуются LCD — не занимать без нужды).

## ⚠️ Предупреждения

1. У клонов ZYLtech перемычка J5 может замыкать 5V на GND — прозвонить до установки.
2. D54–D69 = A0–A15 (54=A0 … 69=A15) — одни и те же пины, разные названия.
3. Драйверы вставлять только при выключенном питании, ориентация EN к метке.

## Команды проверки (из Python или консоли)

```
M119          # состояние концевиков
M106 S128     # DC-мотор (D9) на 50%
M107          # стоп DC-мотора
M42 P40 S255  # ручное управление свободным пином
M280 P0 S90   # серво0 на 90°
M114          # текущие координаты
M112          # аварийный стоп
```
