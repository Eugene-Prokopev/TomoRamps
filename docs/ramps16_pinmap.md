# TomoRamps: RAMPS 1.6 ↔ Arduino Mega 2560

RAMPS 1.6 электрически совместима с классической распиновкой RAMPS 1.4/1.5.
Ниже указаны не только стандартные пины платы, но и их фактические назначения в TomoRamps.

Подробная карта осей: [axis_map.md](axis_map.md).

## Шаговые драйверы

| G-code | Слот | STEP | DIR | ENABLE | Назначение |
|---|---|---:|---:|---:|---|
| X | X | D54 | D55 | D38 | точная X, микровинт |
| Y | Y | D60 | D61 | D56 | точная Y, микровинт |
| Z | Z | D46 | D48 | D62 | грубая X, направляющая около 1 м |
| B | E0 | D26 | D28 | D24 | наклон |
| A | E1 | D36 | D34 | D30 | вращение образца |
| C | внешний TB6600 | D40 | D42 | D44 | точная Z |

Для оси C:

```text
D40 → PUL/STEP TB6600
D42 → DIR TB6600
D44 → ENA TB6600
GND Mega/RAMPS ↔ GND TB6600
Мотор → A+/A-/B+/B- TB6600
```

Все пять RAMPS-драйверов — A4988. Для A4988 установлены микрошаговые перемычки
MS1+MS2+MS3, целевой режим — 1/16. Ток драйверов настраивается по Vref с учётом
номинального тока конкретного мотора.

## Концевики

Механические NO-концевики подключаются так:

```text
COM → GND / контакт '-'
NO  → SIGNAL / контакт 'S'
'+' → не подключать
```

| Физическая ось | G-code | MIN-разъём/вход | Пин Mega | MAX-разъём/вход | Пин Mega |
|---|---|---|---:|---|---:|
| точная X | X | X_MIN | D3 | X_MAX | D2 |
| точная Y | Y | Y_MIN | D14 | Y_MAX | D15 |
| грубая X | Z | AUX signal | D11 | AUX signal | D6 |
| точная Z | C | Z_MIN | D18 | Z_MAX | D19 |
| вращение | A | нет | — | нет | — |
| наклон | B | нет | — | нет | — |

D11 и D6 заняты концевиками грубой X. D18 и D19 используются для точной Z/C.
Не использовать эти пины как свободные выходы.

Ожидаемый результат `M119`:

```text
released → open
pressed  → TRIGGERED
```

## Силовые и служебные выходы

| Разъём/пин | Назначение в текущем проекте |
|---|---|
| D9 / RAMPS MOSFET | DC-мотор 12 V, `M106 S0..255` / `M107`, если подключён внешний DC-контур |
| D11 | MIN-концевик грубой X/Z; не свободен |
| D6 | MAX-концевик грубой X/Z; не свободен |
| D18 | MIN-концевик точной Z/C; не свободен |
| D19 | MAX-концевик точной Z/C; не свободен |
| D40/D42/D44 | STEP/DIR/ENABLE внешнего TB6600; не свободны |
| D4 | не назначать без отдельного согласования |

## Питание и безопасность

- Питание двигателей RAMPS: 12 V DC.
- Общая земля Mega/RAMPS и TB6600 обязательна.
- Драйверы A4988 устанавливать и снимать только при отключённом питании.
- Перед первым движением каждой оси проверить `M119` и держать руку рядом с `M410`.
- Не подавать 12 V на сигнальные входы Mega.

## Команды проверки

```gcode
M17              ; включить удержание моторов
M119             ; проверить концевики
M114             ; прочитать координаты X/Y/Z/A/B/C
M18              ; отключить драйверы
M410             ; быстро остановить движение
M112             ; аварийный останов
```

Для ручной проверки свободных пинов не использовать D6, D11, D18, D19, D40, D42 и D44:
они заняты текущей схемой TomoRamps.
