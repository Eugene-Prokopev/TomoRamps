# Цель G-002: рабочая прошивка Marlin (5 осей + концевики)

**Статус:** готова к запуску пользователем
**Дата:** 2026-08-26

## Задача
Собрать и залить Marlin 2.1.2: оси X, Y (точные), Z (грубая 1 м), I (наклон),
J (вращение) на A4988; концевики X±/Y±/Z±; скорость 250000; EEPROM.

## Критерии приёмки
- [ ] C1: `scripts\setup_firmware.py` — «Патчей применено/проверено: N», без ошибок
- [ ] C2: `scripts\flash.ps1` — сборка без ошибок, `SUCCESS`
- [ ] C3: заливка прошла, Mega перезагрузилась
- [ ] C4 (железо): `smoke.bat COMx` — M115 содержит `MACHINE_TYPE:TomoRamps`,
      M119 показывает статус всех 6 концевиков (при замыкании вручную — TRIGGERED)

## Известные риски
- Стоковые шаги/мм (80,80,80,80,80) почти наверняка неверны → калибровка в G-003.
- G28 I/J пока не работает (концевики I/J не подключены) — хоумим только X Y Z.
- E-STOP на D4 в этой версии конфига не активирован (KILL_PIN в pins_RAMPS занят
  другим пином) — аварийный стоп через GUI (M112). Активация D4 — отдельная задача.

## Откат
- `git revert`; плата перепрошивается повторным запуском flash.ps1.
