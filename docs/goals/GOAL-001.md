## Задача
Каркас Python-стека: G-code-клиент по pyserial, тесты на моках, smoke-скрипт
для реальной платы, минимальный GUI (jog 5 осей + DC-мотор + E-STOP).

## Критерии приёмки
- [ ] C1: `pytest -q` — все тесты зелёные (плата не требуется)
- [ ] C2: `python -m py_compile app/main.py scripts/smoke_serial.py` — без ошибок
- [ ] C3: файлы закоммичены и отправлены на GitHub
- [ ] C4 (железо, выполняет пользователь): `python scripts/smoke_serial.py --port COMx`
      отвечает прошивкой, координатами и статусом концевиков
